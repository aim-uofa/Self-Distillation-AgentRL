### TASK: lifespan ###

For comparing animal lifespans, apply these strategies:

1. Parse the Comparison Direction: Determine whether the task asks for the longest-lived animal, shortest-lived animal, or a sequence of both. Preserve that order explicitly; do not answer a shortest-lifespan request with the most conspicuous animal.

2. Go to the Specified Location: Navigate to the named area through observed connections and inspect the available animals. Use the current episode's candidate set, not a remembered species list from an earlier task or an example in a skill.

3. Identify All Relevant Candidates: Retain each animal's displayed name, including life-stage qualifiers when needed for reference resolution. Exclude plants, furniture, and substances from the animal comparison, and inspect unclear candidates before choosing.

4. Compare Species Lifespans: Distinguish the species' typical lifespan from the current individual's age or displayed stage. A baby is not necessarily from a shorter-lived species than an adult of another species. Compare the actual candidates before selecting an extreme.

5. Focus on the Chosen Animal: Issue `focus on ANIMAL` using the exact observed reference and resolve any ambiguity carefully. Do not replace the required environment interaction with a prose answer naming the animal.

6. Complete Ordered Selections: If both extremes are requested, finish the first focus action before selecting the second. Recheck the instruction and feedback to avoid reversing the sequence or repeatedly focusing on the same candidate without progress.
