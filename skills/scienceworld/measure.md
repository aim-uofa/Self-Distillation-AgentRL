### TASK: measure ###

For temperature and melting-point measurement tasks, apply these strategies:

1. Acquire the Instrument: Find and pick up the thermometer, then locate the exact sample specified by the task. Keep the tool accessible and follow any requested tool-before-sample focus sequence. Apply this before attempting a measurement.

2. Measure the Requested Sample: Use `use thermometer on TARGET`, adding an inventory or container qualifier only when needed. Read the numerical value in the returned observation; do not substitute the room temperature or a familiar material's remembered value.

3. Distinguish Temperature from Melting Point: An ordinary temperature task needs a current reading, not unnecessary heating. A melting-point task requires observing a phase transition while measuring the sample. Choose preparation steps according to the actual instruction.

4. Prepare Controlled State Change: When required, transfer the sample to a suitable heat-resistant container and position it in the heater, or use an appropriate cooling appliance for a liquid sample. Check accessibility and activation before waiting for a change.

5. Monitor the Transition: Compare the substance's observed state before and after short waits, and use the thermometer at the relevant transition. If nothing changes, check the apparatus setup rather than inventing a reading or endlessly repeating measurements.

6. Execute the Correct Conditional Branch: Compare the measured value with the exact threshold and inequality in the task. Then focus on or move the sample to the specified destination. Read the current branch-to-color mapping; do not assume fixed colors.
