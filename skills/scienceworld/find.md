### TASK: find ###

For finding and classifying objects, apply these strategies:

1. Separate Target from Destination: Determine whether the request is for a living thing, non-living thing, plant, or animal, and identify the destination box independently. Do not select the destination container itself as the object to be delivered.

2. Search Likely Locations: Use named locations from the task first. Otherwise prioritize locations plausibly containing the requested category, such as outside or a greenhouse for biological entities. Travel through observed doors rather than assuming an available teleport action.

3. Inspect Visible Candidates: Use recent room observations and inspect open container contents. Open a closed container when necessary. Avoid revisiting exhausted rooms while unexplored plausible locations remain, and do not overlook a matching object already visible.

4. Verify Category and Portability: Select an object that meets the stated category and can support the required follow-up action. Inspect ambiguous candidates; distinguish an animal or plant from unrelated substances and fixed furniture. Keep the object's full observed name.

5. Focus Before Transport When Required: Perform the requested `focus on TARGET` action before moving the object. Acquire it if transport between rooms is needed, then carry it directly to the known destination instead of searching for redundant alternatives.

6. Complete Placement Precisely: Move the selected object into the exact box in the specified room. Use location qualifiers to resolve duplicate names, and check feedback for successful placement rather than assuming that a movement command completed the goal.
